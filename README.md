# Прогнозирование продаж розничной сети
Прогнозирование ежедневных продаж товаров на основе исторических данных.  Цель - построить модель, которая помогает бизнесу оптимизировать закупки и управлять товарными запасами.

**Источник данных:** Store Item Demand Forecasting Dataset

## Подход
1. **EDA** — анализ распределений, сезонности, корреляций
2. **Feature Engineering**:
   - Лаги продаж (1, 3, 10)
   - Скользящие средние (10 дней)
   - Агрегации (средние по товару/магазину)
   - Временные признаки (день недели, месяц, выходные дни)
3. **Модели**:
   - Linear Regression
   - XGBoost
   - LightGBM
   - Optuna для настройки гиперпараметров
4. **Интерпретация:**
   - SHAP-анализ
   - Анализ остатков

## Результаты

| Модель | RMSE | MAE | SMAPE |
|--------|------|-----|-------|
| Linear Regression | 13.49 | 10.95 | 35.16% |
| XGBoost | 6.47 | 4.83 | 16.78% |
| XGBoost + Optuna | 5.69 | 4.29 | 14.92% |
| LightGBM | 6.26 | 4.59 | 15.97% |
| LightGBM + Optuna | 8.34 | 6.09 | 20.58% |
| **XGBoost + Optuna + калибровка** | **5.32** | **3.95** | **13.79%** |

### Лучшая модель: XGBoost с Optuna и калибровкой
- RMSE: **5.32**
- SMAPE: **13.79%**

### Ключевые выводы
- Продажи имеют инерцию
- Цена почти не влияет на спрос
- Промо-акции дают слабый, но заметный эффект
